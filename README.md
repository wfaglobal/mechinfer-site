# mechinfer.com

The published site. Three static files, no build step, no dependencies
beyond Google Fonts.

The source of truth is `site/deploy/` in the private `wfaglobal/mechinfer`
repository, where the page is edited alongside the code that produces the
numbers on it. This repository exists because GitHub Pages is free only for
public repositories; nothing here is secret, since every file is served to
anyone who visits the site.

`CNAME` holds the custom domain and is read by GitHub Pages. Do not delete it.
